# 验证记录

验证环境：Ubuntu 22.04 amd64、GNOME X11。首次验证：2026-10-27；发布副本复验：2026-10-29。

本记录来自集中端到端测试，共 19 项场景通过。测试使用模拟账号及测试网卡，并在独立用户、网络和挂载命名空间验证随包真实后台。未向学校发送测试账号，未改动宿主网络、桌面设置或已安装后台。

默认测试不写系统密钥环。真实校园网账号登录的历史验证与以下模拟测试分开记录，不能以模拟成功代替真实认证。

## 通过的场景

1. 本机实际网卡枚举与 sysfs 一致，IPv4 和 MAC 读取正常且排除虚拟接口
2. GTK 窗口启动、物理网卡列表、默认有线选择及网络详情
3. 实际桌面托盘注册、图标像素、DBusMenu 布局和默认关闭选项
4. GNOME 右上角实际图标及菜单可见，从桌面菜单成功恢复隐藏窗口
5. 通过真实窗口操作完成握手、认证成功、按钮状态与密码存储调用
6. 在线关闭保持同一认证进程；托盘点击及独立进程单实例激活均能恢复窗口
7. 退出认证得到确认，后台进程与通信端口释放
8. 服务器拒绝、用户属性超时、认证超时和后台崩溃均明确报错；802.1X 成功不冒充最终成功
9. 认证中取消，停止后台并恢复输入
10. 网线断开或缺少 IPv4 时，在启动后台前阻止登录并提示
11. 已有客户端占用端口时拒绝接管
12. 退出确认超时会停止本地进程，并说明服务器未确认
13. 成功后可继续重连；取消记住密码会清理密钥；配置与诊断不含密码
14. 退出清理期间重新激活，会在释放旧后台后恢复可用窗口
15. 托盘明确退出会注销图标、发出退出请求并清理线程、后台及端口
16. 无托盘时最小化可恢复；托盘宿主消失自动显示窗口，恢复后自动重新注册
17. 关闭留在托盘选项可持久保存；关闭该选项后窗口关闭会完整退出
18. 独立网络命名空间中的真实后台端到端通信与清理
19. 发布包后台及资源校验一致

## 复现方式

```bash
/usr/bin/python3 tests/end_to_end.py
```

需要可用的图形桌面、StatusNotifierItem 宿主和 unshare 命名空间支持。测试结果在本地 test-results/report.json 生成，该目录不提交。

文档截图仅展示模拟网卡、测试地址和应用菜单，不包含用户桌面、账号、密码或真实登录响应。
